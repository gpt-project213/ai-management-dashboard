# AI Management Dashboard — дашборд руководителя с ИИ-аналитикой

Веб-кабинет руководителя для оптовой компании: финансы, дебиторка, продажи, остатки. Данные берутся из отчётов 1С, ИИ формулирует выводы и находит отклонения. Публичная витрина без боевого кода.

## Интеграция ИИ

- Комментарии к отчётам: что изменилось, где риск, что сделать.
- Классификация должников по срокам просрочки и подготовка сообщений с согласованием менеджером.
- Слой снимков данных с проверкой качества: ИИ работает только с проверенными цифрами.

## Компоненты

Backend с ролевой моделью (директор, руководители, менеджеры), веб-интерфейс, слой снимков и проверки данных, планировщик.

## Технологии

Python, FastAPI, SQLAlchemy + Alembic, React, pandas, LLM-API.

## Место в общей системе: дашборд компании

Проект — один из модулей единой ИИ-платформы управления. Все модули отдают данные в общий дашборд руководителя.

| Блок дашборда | Модуль | Статус |
|---|---|---|
| Финансы, дебиторка, продажи | ai-management-dashboard | работает (внутренняя эксплуатация) |
| Задачи, контроль исполнения, совещания | ai-business-assistant | работает (внутренняя эксплуатация) |
| Подбор персонала | ai-recruiter-agent | пилот запущен на сервере |
| Заказы и диспетчеризация | ai-crm-dispatch | в эксплуатации у клиентов (Pro) |
| Данные учёта из 1С | ai-1c-integration | в разработке |

Статусы указаны честно: «дашборд компании» — целевая архитектура, не все блоки ещё подключены.
